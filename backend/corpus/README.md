## Download

The one-shot `corpus-init` service runs on each stack start. It puts each manifest label that is not in the library into the label queue and asks the ingest worker for a pass. The worker downloads and ingests the queued labels. A label that failed before is queued again on the next start. The Corpus page shows the queue.
